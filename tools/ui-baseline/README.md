# Matjarak 2.0 — المرحلة 0: لقطات مرجعية وفحص الواجهة الحالية

أدوات قياس فقط. لا تغيّر ألوان الهوية ولا الخطوط ولا الشعار، ولا تلمس السيرفر أو قاعدة البيانات أو أي بيئة حقيقية.
لا Staging ولا Production ولا بوسطة ولا Easy Order: كل شيء على قاعدة Docker محلية مؤقتة وتطبيق محلي.

## المكونات

| الملف | الوظيفة |
|---|---|
| `live.sh` | بيئة محلية مؤقتة: MySQL في Docker على `127.0.0.1:3324` (قاعدة `matjarak_ui_baseline`)، مخطط من ملف schema-only، بيانات تجريبية، والتطبيق على `:3008`. بوسطة على عنوان Mock (`DEPLOY_ENV=development`)، والجدولة الخلفية معطلة، وسر الجلسة وكلمة المرور عشوائيان لكل تشغيل (السر في ملف 0600 خارج المستودع: `$TMPDIR/matjarak-ui-baseline.secret`) |
| `seed.ts` | مولّد بيانات تجريبية بأرقام وأسماء وهمية: شركة ببراندين، دفتر مفعّل عبر الخدمات الحقيقية، أوردرات بحالات متنوعة، منتجات، مرتبات، موردون. يرفض أي قاعدة غير المحلية المؤقتة |
| `capture.mjs` | Chrome headless عبر CDP: لقطات لكل شاشة بخمسة عروض (360/390/768/1280/1440) × فاتح/داكن، ولقطة 1280 باتجاه LTR مُجبَر، وفحص axe كامل (بما فيه التباين) على 1280 بالوضعين، وأخطاء الكونسول. يرفض أي رابط غير localhost |

اختبارات المرحلة 0 الآلية في `client/src/design-audit/` وتعمل ضمن `vitest` العادي:
`tokenContrast.test.ts` (التباين من الـtokens)، `directionAudit.test.ts` (الاتجاهات في المكونات المشتركة)، `a11yShared.test.tsx` (axe على المكونات المشتركة بالاتجاهين).

## إعادة توليد الـ220 لقطة

المتطلبات: Docker، و Google Chrome (أو `CHROME_BIN`)، و`node_modules` مثبتة، وملف **مخطط فقط** (بلا بيانات) لنفس الـcommit.

1. ملف المخطط: من قاعدة اختبار **محلية** بُنيت لنفس الـcommit (لا Staging ولا Production أبدًا)، مثلًا:

   ```bash
   docker exec <local-test-container> mysqldump -uroot -proot --no-data --skip-comments <local_test_db> > /tmp/test-schema.sql
   ```

2. تشغيل البيئة (يبني القاعدة ويزرع البيانات أول مرة، ثم يشغّل التطبيق على `:3008`):

   ```bash
   SCHEMA_SQL=/tmp/test-schema.sql bash tools/ui-baseline/live.sh
   ```

3. المعرّفات من القاعدة المحلية (المالك `owner27`، المحاسب `acc27u`، إدخال البيانات `de27u`، والأوردر `UI-2004`):

   ```bash
   docker exec mj-ui-baseline mysql -uroot -proot -N matjarak_ui_baseline -e "SELECT username, id FROM employees WHERE username IN ('owner27','acc27u','de27u'); SELECT id FROM orders WHERE orderNumber='UI-2004';"
   ```

4. الالتقاط (حوالي 20 دقيقة: 20 شاشة × 11 لقطة):

   ```bash
   node tools/ui-baseline/capture.mjs --out ui-baseline/<YYYY-MM-DD>_<commit> --owner <id> --accountant <id> --dataentry <id> --order <id>
   ```

   خيارات للتجربة السريعة: `--only orders,ledger-daily` و `--widths 390,1280`.

5. الإيقاف والتنظيف: أوقف التطبيق (Ctrl+C)، ثم `docker rm -f mj-ui-baseline`.

## مكان الحفظ — خارج Git دائمًا

- الناتج في مجلد `ui-baseline/<YYYY-MM-DD>_<commit>/` في جذر المستودع: `<screen>__<width>__<light|dark>.png` و`<screen>__1280__ltr.png` و`report.json` (axe + أخطاء الكونسول + المسار النهائي لكل لقطة).
- **لا يُضاف للـGit أبدًا** (حوالي 35MB لكل مرجع). على كل جهاز أضف السطر `/ui-baseline/` إلى `.git/info/exclude` (استبعاد محلي لا يدخل أي commit)، وتأكد بـ`git check-ignore -v ui-baseline/<run>/report.json`.
- المرجع الأول: `ui-baseline/2026-10-15_23be803/` (220 لقطة، الواجهة عند `23be803`). الـcontact sheets (`contact-sheets/sheet-0N.jpg`) مُولَّدة من نفس المجلد.
- للاحتفاظ طويل المدى: انسخ المجلد كأرشيف خاص (مثلًا ملف zip في تخزين الشركة الخاص) — ليس في المستودع ولا في أي مكان عام.

## استرجاع المرجع البصري لاحقًا

- **من الأرشيف:** فك المجلد في `ui-baseline/` وقارن اللقطات بنفس الاسم (نفس الشاشة/العرض/الوضع).
- **بإعادة التوليد:** افحص (`git worktree add`) الـcommit المرجعي ثم نفّذ خطوات «إعادة التوليد» بنفس `seed.ts` — البيانات حتمية (نفس الأوردرات والأرقام)، والفروق المتوقعة فقط: التواريخ النسبية («اليوم») والوقت المعروض.
- **المقارنة:** نفس المسار والاسم في مجلدين (`<before>` و`<after>`)؛ الـcontact sheet يعرض لكل شاشة 1280 فاتح/داكن/LTR و390 فاتح/داكن.

## ملاحظات القراءة

- اللقطة كاملة الصفحة حتى 4000px؛ العناصر الثابتة (شريط الموبايل السفلي) تظهر في موضعها من نافذة 800px.
- لقطة `__ltr` تقلب `dir` على جذر الصفحة فقط. لأن `dir="rtl"` مكتوب داخل 92 ملفًا (160 مرة) عند `23be803`، الواجهة **لا تنقلب فعليًا** — اللقطة تكشف ذلك ولا تمثل واجهة إنجليزية.
- `/__manus__/debug-collector.js` يظهر خطأ كونسول في بيئة التطوير المحلية فقط (يرجع HTML) — ليس من الواجهة.
- شاشة إدخال فيسبوك بوابة موظف: تُلتقط بجلسة موظف إدخال البيانات (بجلسة المالك تبقى «جاري التحميل» ثم تحوّل للدخول).
